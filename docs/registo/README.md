## Como escrever um registo

O ficheiro chama-se `tarefa-NN-nome.md` e tem estas secções, por esta ordem:

1. **Objetivo**
2. **Decisões técnicas:** opção escolhida, alternativas consideradas e porquê.
3. **Decisões de negócio:** tomadas ou confirmadas, e por quem.
4. **Ficheiros criados ou alterados**
5. **Como funciona:** explicação técnica para alguém que não leu o código.
6. **Comandos de verificação e resultados**
7. **Problemas encontrados e como foram resolvidos**
8. **Pendentes para tarefas seguintes**

Os registos das tarefas 0, 1 e 2 foram escritos em retrospetiva, a partir do git log e das descrições dos PR. O que essas fontes não dizem está assinalado como "não registado", em vez de reconstruído de memória.
